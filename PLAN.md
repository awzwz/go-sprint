# План спринта: Go Backend за 30 дней

Темп 5+ часов в день. Каждый день — коммит на GitHub.

**Цель:** задеплоенный REST API на Go с PostgreSQL, живая ссылка, чистый README.

Ежедневный режим: ~2 ч проект · ~1,5 ч практика Go · ~1 ч алгоритмы · ~30 мин теория/английский.
